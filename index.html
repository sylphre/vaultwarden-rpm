Vaultwarden rpm repository

This repository contains rpm packages of Vaultwarden, a Bitwarden-compatible API server written in Rust. They can be installed in AlmaLinux and other Enterprise Linux rebuilds.

See the GitHub repository for more information.

Installing the repository

To install Vaultwarden and add this repository, run this for AlmaLinux 10 (el10):

curl -sSfL https://sylphre.github.io/vaultwarden-rpm/el/10/install.sh | sudo bash
sudo dnf install vaultwarden

To install Vaultwarden and add this repository, run this for AlmaLinux 9 (el9):

curl -sSfL https://sylphre.github.io/vaultwarden-rpm/el/9/install.sh | sudo bash
sudo dnf install vaultwarden
